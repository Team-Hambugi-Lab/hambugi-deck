고치다 보니 같은 기관 안내가 갈라졌다

문제 · 위험 상황 안내 테이블

  • 근로복지공단 정보가 지사별 행마다 그대로 복사돼 있었다
  • 안내 문구도 행마다 복사돼, 임금체불 2행 중 한 행에만 지역 대표번호가 들어가며 내용이 갈라졌다
  • 미확인 값이 컬럼마다 "N/A"와 빈칸으로 제각각
  • 외래키 검증이 이 테이블은 검사하지 않았다

해결 · 1주차에 배운 정규화 그대로

  • 중복된 지사 행을 하나로 병합
  • 안내 문구를 별도 테이블(risk_keyword_messages)로 분리
  • 미확인 표기 통일, 컬럼별 빈칸 의미를 README 표로
  • 외래키 검증 스크립트를 reference 테이블까지 확장

갱신 이상(update anomaly)을 실제로 겪고 고친 사례 · visa-data #45, PR #50 (김태은)
